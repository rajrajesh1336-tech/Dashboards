# Dashboard
This repository contains the Power BI dashboards I made during my Data Science and Generative AI course.

## 1. PBI_Fraud_Analysis.pbix
- **Project:** Mobile Financial Transactions Fraud Analysis
- This dashboard shows the fraud trends in mobile financial transactions. I made it for my project Fraud Detection in Mobile Financial Transactions.
---
**What is in the dashboard**
- KPI cards: Total Transactions, Fraud Transactions, Fraud Rate, Transaction Amount and Fraud Amount
- Bar chart: fraud and non-fraud transactions by transaction type
- Column chart: total transactions by fraud status
- Line chart: how fraud changes over time
- Donut chart: fraud amount by transaction type (like TRANSFER and CASH_OUT)
--- 
**Filters**

- You can filter the dashboard by:
  - Transaction Type
  - Step (time)
  - Fraud Status
  --- 
**How to open it**
- Download the PBI_Fraud_Analysis.pbix file.
- Open it in Power BI Desktop.
